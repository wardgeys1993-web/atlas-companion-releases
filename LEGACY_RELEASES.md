# Legacy Atlas release provenance

The records in releases/0.13.0, releases/0.13.1, releases/0.14.0 and releases/0.15.0
document the original GitHub Release assets and verified checksums.

The four existing version tags remain at the original 0.12.0 metadata commit
4c23a7a56bf8f615b7d749163845dd73c4e0e17b. These recovery commits were recorded
later. They are not the original build commits, and they do not change any tag,
release URL, asset ID or download bytes. Full historical source provenance is
unknown and is recorded as null, rather than inferred from current development.

Future releases require a private source commit and version tag, an exact-source
build, a new public metadata commit and version tag, and verified release assets.
