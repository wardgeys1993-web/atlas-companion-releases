# Atlas Android 0.18.1

Atlas is back on the phone with the current desktop droid: the compact E3 body,
pointy sensor ears and amber eyes. Home, Chat, alarms, the launcher, widget and
update screens use the Atlas identity again.

The interface pairs warm amber light and charcoal panels with Chakra Petch
headings and Manrope text. Reduced motion and background animation pauses remain
available. The app keeps the same package and signing identity for an in-place
update that preserves pairing and saved phone data.

Android version: 0.18.1, code 36. Requires Android 8 or later.
This release contains the Android app and its update metadata.

Validation: 158 Android JVM tests pass, with no failures, errors or skips.
Native render checks cover the current pointed ears, sleeping pose, reduced
motion and large text. Android lint has no errors. The APK signature, embedded
version, update manifest and checksums are verified before publication.
These render checks run in Robolectric; a physical phone install and owner
visual acceptance are still pending.

Open Home in the phone app, find App update, then choose Check now. Review the
downloaded update and approve Android's installation prompt.
