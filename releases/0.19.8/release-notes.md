# Atlas Companion 0.19.8, Atlas Engine 0.32.0

Atlas Engine 0.32 reuses compatible prepared prefixes across release labels, with full model-content checks, exact prompt tokens and versioned state compatibility.

Cache identities follow the downloadable runtime. Development-only prototypes do not invalidate installed prefixes; changed model execution or prompt content still requires rebuilding.

Explicit self-contained native 80B file reads, directory listings and file searches focus model argument generation and display complete bounded tool receipts without a second answer generation.

Full tool schemas, permissions, untrusted-data markers and normal handling of ambiguous requests remain. Other Qwen, Gemma and managed inference paths remain available. Android receives matching release metadata.

Compatible restarts avoid an unnecessary full-prefix rebuild. A first uncached preparation is still expensive. Scoped tests do not establish universal speed, full-product or physical-device acceptance. No sustained token-generation improvement is claimed in this release.
