# Atlas Companion 0.12.0: More room for your thoughts

Android version 0.12.0, code 18.

- Incoming links, photos, suggestions and dictated text preserve an unfinished message. Choose whether to add the new content, replace the draft, start a new chat or keep what you have.
- Reusing an earlier request opens an editable draft. Atlas waits for your tap before sending it again, and asks you to reattach photos when needed.
- First-time setup guides you through connecting your PC and asking your first question. Connection status now distinguishes a saved PC, an active attempt, a user disconnect and a failed link.
- Chat gives the conversation more space with a smaller header, Atlas rail and empty state.
- Voice controls announce their active stop action. After microphone permission is denied, the app offers a path to Android settings.

## Install

In Atlas on Android, open **Companion > App update > Check now**. Android asks before installing the downloaded APK. You can also download the APK attached to this release. This build uses the same signing certificate as 0.11.0.

## Verification

The Android build completed, all 67 unit tests passed, and lint reported zero errors and 31 warnings. The APK version, byte count and SHA-256 match the attached manifest. Rendered Chat layouts were inspected. Physical OnePlus installation, pairing, TalkBack and microphone checks remain unverified.
