# Atlas Companion 0.18.7

This release brings the merged desktop and Android UI refinements to the same version.

- Home presents model readiness, current work and useful next actions.
- Desktop improves compact layouts, text scaling, model setup and approval visibility.
- Android improves conversation navigation, reply actions, memory, projects and linking. Text-only drafts restore without a phantom image attachment, and local demo chat reconnects after returning from the background.
- Mission results show reported progress, available evidence and uncertainty.
- Both apps retain the Atlas droid, local-first behavior and existing signing identities.

The release is qualified with deterministic tests and desktop and Android emulator checks. Emulator validation does not certify physical-phone audio, Wi-Fi or real-model response quality.
